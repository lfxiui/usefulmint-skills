# Pasteable prompt

Build an original color palette and usage notes for a small brand, delivered as editable SVG and CSS values.

Infer the brand mood from the brief, choose five purposeful colors, and name their roles: primary, secondary, background, surface and accent. Show the palette as large shapes and include exact hex values. Calculate contrast for proposed text/background pairs and state the numbers. Colors without enough contrast can be decorative only.

Default 1200 by 750 canvas. Sample Moss palette: #294c3b, #c8d9a8, #e9edde, #f8f1e3, #df7650. Use five generously sized swatches with visible hex values, one headline and consistent safe margins. Adapt the colors to the user rather than always applying green.

Use my language and real material. Deliver SVG palette and CSS color values with editable source, inspect the actual result, and report any unverified export. Do not publish or buy anything.
