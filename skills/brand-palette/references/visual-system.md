# Visual system

Default 1200 by 750 canvas. Sample Moss palette: #294c3b, #c8d9a8, #e9edde, #f8f1e3, #df7650. Use five generously sized swatches with visible hex values, one headline and consistent safe margins. Adapt the colors to the user rather than always applying green.

Check the final artifact at its intended size: main subject visible, labels legible, hierarchy clear, no accidental clipping, keyboard actions reachable, and source attribution accurate. Reuse these principles for new content without copying a third-party layout.
