# Small Data Stories

Start with the provided table and question. Preserve the original data and compute totals, denominators, rounding and missingness before designing. Distinguish a share of one population from a comparison across categories; use separate labels for separate questions. Choose bars for comparison, a line for ordered time, and a ring only for a part of a well-defined whole. Keep proportional geometry and a zero baseline for bars. Do not infer causal claims. Label synthetic example data directly on the chart. Deliver the source values and calculations next to the editable SVG. Read references/visual-system.md before rendering.

## Deliver and inspect

Preserve the user’s language and use only supplied or original assets. Save editable source files in a new output folder. Open every output, inspect typography, cropping and target-size readability, and repair actual problems before handing off. State what was created and which source data or assets were used. A browser self-review is not an independent reproduction test. Do not publish or purchase assets unless the user authorizes it.

## Visual guidance

Use a warm near-white #f7f7ed ground and one dark-green #547143 accent. One question, one main chart and a short takeaway per card. Source, denominator, unit and date are part of the final artifact, not hidden metadata. A ring needs circumference-based segments. Bar lengths must share one scale. The local sample has two separate synthetic questions: 144 of 200 respondents willing to record ideas, and inspiration-channel shares 35/25/25/15. It is not a real survey.
