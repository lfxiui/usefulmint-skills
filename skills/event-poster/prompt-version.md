# Open Studio Poster

Create two distinctly composed poster directions from the same event brief. Identify the event name, intended audience, venue, time zone, dates and the call to action. Do not invent missing event details: ask when publication depends on them. If the task is a fictional concept, label it as such. Make the event name and one original geometric or photographic motif carry the composition. Keep secondary details on a consistent baseline and away from art. Read references/visual-system.md for composition and legibility constraints.

## Deliver and inspect

Preserve the user’s language and use only supplied or original assets. Save editable source files in a new output folder. Open every output, inspect typography, cropping and target-size readability, and repair actual problems before handing off. State what was created and which source data or assets were used. A browser self-review is not an independent reproduction test. Do not publish or purchase assets unless the user authorizes it.

## Visual guidance

Use a 1200 × 750 landscape canvas by default; adapt to the requested channel. The sample uses cobalt #243cda, cream #faf2d9 and apricot #ffba87. Set one 80–120px headline, a generous motif area, and a compact detail band. The alternate must change hierarchy or motif, not merely colors. Avoid third-party event logos. Keep essential dates and CTA readable at the intended size.
