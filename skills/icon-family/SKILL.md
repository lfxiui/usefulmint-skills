# Little Things Icons

List the actual actions and intended display sizes. Draw original vector paths on a shared grid, using a consistent stroke, cap style, join and corner vocabulary. Adjust circles and diagonals optically instead of assuming identical numeric widths appear equal. Avoid brand trademarks unless provided and authorized. Read references/visual-system.md. Deliver an editable SVG sheet; supply individual SVG exports if requested. Render and inspect icons at 16, 24 and 48px, simplify any symbols that collapse at the target size.

## Deliver and inspect

Preserve the user’s language and use only supplied or original assets. Save editable source files in a new output folder. Open every output, inspect typography, cropping and target-size readability, and repair actual problems before handing off. State what was created and which source data or assets were used. A browser self-review is not an independent reproduction test. Do not publish or purchase assets unless the user authorizes it.
