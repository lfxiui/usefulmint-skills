# Good Things Deck

Clarify the audience, the decision the deck should support and the source material. Make three slides unless the user requests another length: the central idea, the proposed approach, and the smallest actionable next step. Each slide should communicate one point through an original visual composition. Replace unsupported claims with questions or clearly marked hypotheses, never invented traction. Read references/visual-system.md. Produce editable SVG pages and concise speaker notes; if a presentation tool is available, use its actual format, but do not label SVG files as PowerPoint.

## Deliver and inspect

Preserve the user’s language and use only supplied or original assets. Save editable source files in a new output folder. Open every output, inspect typography, cropping and target-size readability, and repair actual problems before handing off. State what was created and which source data or assets were used. A browser self-review is not an independent reproduction test. Do not publish or purchase assets unless the user authorizes it.
