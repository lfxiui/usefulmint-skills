# Sketch Notes

Create SVG knowledge card from the user's real material. Use the user's language. Read references/visual-system.md before composing.

## Understand and compose

Identify the intended audience, the one message and the supplied assets. If the request is sufficient, state a brief assumption and proceed. Ask only for missing input that changes the result. Preserve factual claims and use authorized images; never invent metrics, customers or product capabilities.

Identify 3–5 ideas and the relationships between them. Draw a clear diagram instead of placing paragraphs in boxes. Use a distinct visual symbol for each idea and visible directional arrows. Use short labels under each figure. When an idea cannot be illustrated, preserve its exact meaning rather than inventing evidence.

## Deliver and verify

Create a fresh output folder with editable source and a short source/usage note. Open the actual result in a browser, check every page and control, inspect desktop and phone width, and repair clipping or unreadable copy. Keep the original assets intact. Report actual formats and files; do not rename files to imply unsupported export.

Do not publish, send messages, purchase assets or start paid generation without authorization. A locally reviewed sample does not establish compatibility with tools that were not run.
