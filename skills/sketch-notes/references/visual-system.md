# Visual system

Default 1200 by 750 canvas, 56px safe margins, ink #212b25 on warm yellow #f5d945. Use 4–5px rounded linework, asymmetric but aligned diagram elements, headings 60–70px, labels at least 28px. Avoid tiny footnotes and unsupported facts.

Check the final artifact at its intended size: main subject visible, labels legible, hierarchy clear, no accidental clipping, keyboard actions reachable, and source attribution accurate. Reuse these principles for new content without copying a third-party layout.
